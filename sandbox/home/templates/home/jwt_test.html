Guia de Integração e Especificação dos Endpoints JWT

A sub-aplicação django_suap_auth.jwt disponibiliza endpoints para autenticação JWT direta com o SUAP sem requerer dependências como Django REST Framework (DRF).

Como Ativar no seu Projeto Django

# 1. Em settings.py:

INSTALLED_APPS = [
    ...,
    "django_suap_auth",
    "django_suap_auth.jwt",  # Ativação da sub-aplicação JWT
]

# 2. Em urls.py:

urlpatterns = [
    path("api/token/", include("django_suap_auth.jwt.urls")),
]

Endpoints Disponíveis

POST /api/token/pair/ Obtenção de Tokens

Descrição: Autentica o usuário no SUAP usando matrícula e senha e retorna um par de tokens JWT (Access e Refresh).

Payload da Requisição (JSON):
{
  "username": "1234567",
  "password": "sua-senha-suap"
}
Exemplo cURL:
curl -X POST http://localhost:8000/api/token/pair/ \
  -H "Content-Type: application/json" \
  -d '{"username": "1234567", "password": "sua-senha-suap"}'
POST /api/token/refresh/ Renovação de Token

Descrição: Recebe um Refresh Token válido e gera um novo Access Token.

Payload da Requisição (JSON):
{
  "refresh": "<refresh_token>"
}
Exemplo cURL:
curl -X POST http://localhost:8000/api/token/refresh/ \
  -H "Content-Type: application/json" \
  -d '{"refresh": "<refresh_token>"}'
POST /api/token/verify/ Verificação de Token

Descrição: Verifica se o token JWT fornecido é válido no SUAP.

Payload da Requisição (JSON):
{
  "token": "<access_or_refresh_token>"
}
GET / POST /api/token/user-info/ Consumo de Dados Autenticado

Descrição: Executa requisições na API do SUAP em nome do usuário autenticado utilizando o Access Token JWT.

Forma 1: Via Cabeçalho de Autenticação (Recomendado)
curl -X GET http://localhost:8000/api/token/user-info/?endpoint=/api/rh/eu/ \
  -H "Authorization: Bearer <access_token>"
Forma 2: Via Corpo da Requisição JSON
{
  "token": "<access_token>",
  "endpoint": "/api/rh/eu/"
}
